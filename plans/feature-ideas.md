# Идеи новых функций

Список от 30.09.2026, **владелец изучает, ничего не начато**. Порядок — по пользе. Новые виды
тренировок (зал, кроссфит, велосипед, йога) вынесены в отдельный план `activity-types.md`.

Ограничение из `conventions-and-status.md`: всё бесплатно, без монетизации.

## В первую очередь

1. **Экспорт и импорт всей истории в файл.** Бэкап, перенос на новый телефон и
   безболезненная смена ключа подписи перед RuStore (`build-ci-and-signing.md`). Сейчас есть
   только GPX по одной тренировке. Делать до или сразу после этапа 1 в `activity-types.md`:
   этапы меняют формат сессии.
2. **Голосовые подсказки на бегу:** каждый километр или каждые N минут — «Километр 3, темп
   6:12, пульс 148». Смотреть на экран на бегу неудобно; голос работает при заблокированном
   экране.
3. **Тренировка по целевой зоне с сигналом.** Выбор зоны уже есть (`TargetZonePicker`).
   Добавить вибрацию/звук при выходе из зоны: «выше — сбавь», «ниже — прибавь».

## Потом

4. **Сплиты по километрам** в итогах: км — время — темп — средний пульс.
5. **Цели на неделю:** «3 тренировки», «10 км», «60 минут в зоне 2» — прогресс в карточке
   «Эта неделя».
6. **Пульс восстановления:** насколько упал пульс за минуту после финиша. Нужна минута
   записи после «Стоп».

9. Виджет на рабочий стол со сводкой недели.
