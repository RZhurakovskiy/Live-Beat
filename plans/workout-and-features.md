# Фичи, экраны и навигация

## Навигация (`src/navigation/`)

**Три вкладки плюс стек поверх них.** У всех экранов `headerShown:false` — каждый рисует свой
хедер через `ScreenHeader`. Кнопок «назад» на вкладках нет (их нет и в макетах): между
разделами ходят табом. На pushed-экранах (`SessionDetails`, `Stats`, `BleLog`) шеврон есть —
иначе уйти с них нечем.

Начальный маршрут решается в `App.tsx` по флагу `onboarding_done`: свежая установка
открывается на `Welcome`, остальные — сразу на `Tabs`.

**Вкладки** (`TabParamList`):

| Вкладка | Экран | Заметки |
|---|---|---|
| `Workout` | `HomeScreen` | Выбор режима и старт. |
| `History` | `HistoryScreen` | За биометрическим гейтом. |
| `Settings` | `SetupScreen` | Тот же экран, что и шаг интро, без кнопки завершения. |

**Стек** (`RootStackParamList`):

| Экран | Параметр | Заметки |
|---|---|---|
| `Welcome` | — | Интро, только на свежей установке. |
| `Setup` | — | Чек-лист настройки как шаг интро. |
| `Tabs` | — | Вложенный таб-навигатор. |
| `ScanDevice` | — | Модалка. Сопряжение датчика. |
| `ActiveWorkout` | — | `gestureEnabled:false` (нельзя смахнуть посреди тренировки). |
| `WorkoutSummary` | `{ session }` | `gestureEnabled:false`. Тренировка ещё **не** в базе. |
| `SessionDetails` | `{ sessionId }` | За биометрией; экспорт GPX. |
| `Stats` | — | Статистика и прогресс; вход из карточки «Эта неделя». |
| `BleLog` | — | Журнал датчика; вход из секции датчика в настройках. |

Экран внутри вкладки объявляет пропсы через `TabScreenProps` (`CompositeScreenProps`) —
иначе он не может открыть экран стека.

## Экраны

- **WelcomeScreen** — интро на свежей установке. ⚠️ Фото из макета нет, на его месте карточка
  с брендовым градиентом; `<Image>` подставляется без правки вёрстки вокруг.
- **SetupScreen** — чек-лист: профиль (сохраняется по `onBlur`), системные разрешения с
  тумблерами (выданное разрешение залочено — приложение не может его отозвать), датчик с
  живым пульсом и вход в журнал. Он же вкладка «Настройки».
- **HomeScreen** — выбор режима крупными карточками, карточка целевой зоны, «Начать
  тренировку» (недоступна без датчика), кликабельная строка-футер про датчик.
  Авто-переподключение к последнему известному устройству при монтировании.
- **ScanDeviceScreen** — три состояния: сканирование (радар), найдено (список с ID и уровнем
  сигнала), ошибка. Тап **выбирает**, подключает нижняя кнопка.
- **ActiveWorkoutScreen** — крупный BPM, пилюля зоны, `ZoneLegend`, карта (улица) или
  HR-график (дорожка), плитки. **Вибро-сигнал целевой зоны** (с кулдауном, на паузе отключён).
  **Пауза** — кнопка с удержанием, дальше оверлей «Продолжить» / «Завершить».
  **Баннеры состояний** — потеря линка / контакта / ожидание GPS, каждый со своей деградацией
  контента. Держит экран включённым и гоняет foreground-сервис.
- **WorkoutSummaryScreen** — итоги и разбивка по зонам. **Тренировка здесь ещё не в базе:**
  «Сохранить тренировку» пишет её, «Отбросить» выкидывает (с подтверждением).
- **HistoryScreen** — карточка «Эта неделя» (тап → статистика), чипы-фильтры, плоский список;
  строка → SessionDetails. Пустое состояние по макету.
- **SessionDetailsScreen** — сохранённая тренировка: статистика, HR-график, карта маршрута;
  **шэринг GPX** для уличных сессий (`utils/gpx.ts` + expo-file-system + expo-sharing).
- **StatsScreen** — итоги за 7/30 дней, время в зонах, плюс три блока прогресса:
  пульс на сравнимом темпе, динамика по неделям, личные рекорды (`utils/progress.ts`).
- **BleLogScreen** — кольцевой журнал событий датчика (подключения, потеря контакта, заряд,
  `is not advertising`). У релизной сборки нет Metro-консоли, так что это единственный способ
  посмотреть, что произошло с датчиком, прямо с телефона. Есть «поделиться» и «очистить».

## Режимы тренировки

- **treadmill** — только пульс.
- **outdoor** — пульс + GPS-маршрут. `src/location/backgroundLocation.ts` регистрирует
  задачу TaskManager (`pulse-background-location-task`) и стартует
  `Location.startLocationUpdatesAsync` со **своим** foreground-сервисом; каждая точка
  дописывается в `activeWorkout.route` через стор. Маршрут рисует `RouteMap` (MapLibre +
  тайлы OpenFreeMap). Дистанция/темп из `utils/geo.ts`.

## Устойчивое к вылету сохранение тренировки (`src/workout/`)

Android может убить приложение посреди тренировки (энергосбережение, нехватка памяти). Чтобы
не терять пробежку:
- **`workoutDraft.ts`** — `startWorkoutDraftAutosave()` подписывается на session-стор и пишет
  идущую тренировку в таблицу `workout_draft` максимум раз в ~10 с, и сразу же, когда
  приложение уходит в фон (момент, когда убийство наиболее вероятно).
- **`restoreWorkoutDraft()`** (вызывается в `App.tsx` на старте) — возвращает убитую
  тренировку в стор и, для улицы, перезапускает GPS-трекинг.
- **`workoutDraftCodec.ts`** (чистый, тестируемый) — кодек + валидация JSON черновика;
  битый или устаревший черновик отбрасывается.
- **`workoutService.ts`** — `beginWorkoutService()` / `endWorkoutService()` владеют
  foreground-сервисом тренировки, а заодно **watchdog'ом** «тихого» обрыва BLE: пока идёт
  тренировка, раз в 10 с зовётся `recoverIfStale(20000)`.

## Безопасность / приватность

- История и детали сессии закрыты **`useBiometricGate()`**
  (`src/hooks/useBiometricGate.ts`): отпечаток/лицо при фокусе; если на устройстве биометрия
  не заведена — пропускает; при провале уводит назад.
- Все данные — на устройстве (SQLite). Нет аккаунтов, нет аналитики, нет сети, кроме тайлов карты.

## Общие UI-компоненты (`src/components/`)

Все берут токены из `src/theme.ts`; цвета и размеры не хардкодятся.

**Каркас экрана** (появился при редизайне, используется везде):
`ScreenHeader` (вордмарк + бейдж состояния), `StatusBadge` (4 тона), `ScreenTitle`
(крупный заголовок + подзаголовок), `SectionCard` (карточка-секция, варианты
`plain`/`active`/`complete`), `BottomCta` (нижняя кнопка + вторичная + футер),
`FilterChips` (чипы, счётчик опционален).

**Экранные блоки:** `ModeCard` (выбор режима), `TargetZoneCard` (свёрнутая целевая зона),
`WeekSummaryCard` («Эта неделя»), `WeeklyBars` (столбики по неделям), `StateBanner`
(баннеры активной тренировки), `HoldButton` (кнопка с удержанием), `PauseOverlay`,
`ScanPulse` (радар сканирования), `SignalBars` (уровень сигнала датчика).

**Данные и графика:** `Preloader` (анимированный SVG-сплэш), `GradientButton`, `StatTile`,
`HeartRateChart` (самописный SVG), `RouteMap` (MapLibre), `TargetZonePicker`, `ZoneLegend`.
