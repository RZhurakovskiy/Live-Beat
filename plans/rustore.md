# Публикация в RuStore

Решение владельца 02.10.2026: раздача через RuStore названа главным вопросом дистрибуции.
Приложение бесплатное, без рекламы и подписок. Здесь всё для выхода в магазин: требования
(сверены с документацией RuStore 02.10.2026), чек-лист, команды для ключа, готовые тексты
карточки и обоснований разрешений, открытые вопросы. Пайплайн сборки и подпись описаны в
`build-ci-and-signing.md`, политика конфиденциальности лежит в `../docs/privacy-policy.md`.

## Главное: ключ подписи

Магазин запоминает подпись первой загрузки, все обновления обязаны быть подписаны тем же ключом
и иметь тот же package. Потеряли ключ: обновлять приложение в магазине больше нельзя. Нынешний
standalone-APK подписан публичным debug-ключом из репозитория, с ним в RuStore нельзя загружать
ничего, даже пробную версию. Код релизной подписи готов (`scripts/sign-release-apk.sh`, шаг в
CI), нужен сам ключ и секреты.

## Что требует RuStore (проверено 02.10.2026)

- **Файл:** APK или AAB до 5 ГБ, подписан цифровым сертификатом, имя пакета уникально; у
  следующих версий подпись и пакет те же, что у предыдущей
  ([публикация](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication)).
- **Подпись** ставит сам разработчик своим ключом. В их гайде пример: RSA 2048, срок 10000 дней;
  для AAB подпись ещё загружают в консоль ([гайд](https://rustore.ru/help/guides/sign-apk)).
- **Карточка:** иконка 512×512 PNG или JPG, залитая по всей площади (на одной странице лимит
  3 МБ, на другой 1 МБ, держать до 1 МБ); минимум 3 скриншота на тип устройства; название до 30
  символов и уникальное; категория; возрастное ограничение; краткое описание до 80 символов,
  полное до 4000; контакты (почта, сайт, VK или MAX).
- **Разрешения:** всё, кроме Normal, считается чувствительным. Для каждого в разделе
  «Безопасность данных» заполняется поле «Назначение», плюс анкета типов данных. Если найдены
  опасные разрешения, команда проверяет тщательно и при неубедительном ответе пишет на почту;
  разрешения из запрещённой категории отклоняются сразу при загрузке
  ([как объявлять](https://www.rustore.ru/help/en/developers/publishing-and-verifying-apps/app-publication/new-version-app/declare-app-permissions/how-to-declare-permissions)).
- **Модерация** по описанию RuStore: проверка разработчика, анализ разрешений, антивирусы,
  ручная проверка. Сроков в документации нет.
- **Правила:** функции работают стабильно, без навязчивой рекламы, язык русский или английский,
  честные скриншоты. Отдельная строка: если приложение работает с персональными данными,
  разработчик должен быть признан оператором персональных данных
  ([требования](https://www.rustore.ru/help/en/developers/publishing-and-verifying-apps/requirement-apps)).
- **Аккаунт физлица** бесплатный, «для личного использования» (студенты, любители). По
  описанию 2023 года: VK ID, страница или сайт, онлайн-проверка паспорта и лица. Сверить при
  регистрации ([регистрация](https://www.rustore.ru/help/developers/developer-account/registration-developer)).
- **Категория:** фитнес-приложения RuStore относит к «Спорт», «Здоровье» не добавлять
  ([категории](https://www.rustore.ru/help/en/developers/publishing-and-verifying-apps/app-publication/new-version-app/category)).

## Релизный ключ и секреты

Ключ создаёт владелец сам: пароль не должен попасть в чат или репозиторий. `keytool` стоит
внутри Android Studio, в PATH его нет. PowerShell:

```powershell
# 1. Папка для ключей вне репозитория
New-Item -ItemType Directory -Force "$HOME\livebeat-keys" | Out-Null

# 2. Ключ. Спросит пароль два раза: придумайте и сразу сохраните в менеджер паролей.
& "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v `
  -keystore "$HOME\livebeat-keys\livebeat-release.p12" -storetype PKCS12 `
  -alias livebeat -keyalg RSA -keysize 2048 -validity 10000 `
  -dname "CN=Roman Zhurakovskiy, O=LiveBeat, C=RU"

# 3. Файл ключа в base64, уходит в буфер обмена (для секрета RELEASE_KEYSTORE_BASE64)
[Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\livebeat-keys\livebeat-release.p12")) | Set-Clipboard

# 4. Отпечаток сертификата: записать рядом с ключом, потом сверять с логом CI
& "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -list -v -keystore "$HOME\livebeat-keys\livebeat-release.p12" -alias livebeat | Select-String "SHA256"
```

Копию `livebeat-release.p12` и пароль хранить минимум в двух местах (менеджер паролей и
флешка или облако). Команда проверена на этой машине: ключ создаётся, им подписывается
настоящий APK.

Секреты: репозиторий на GitHub, Settings, Secrets and variables, Actions, New repository secret.

| Секрет | Значение |
|---|---|
| `RELEASE_KEYSTORE_BASE64` | содержимое буфера обмена после шага 3 |
| `RELEASE_KEYSTORE_PASSWORD` | пароль из шага 2 |
| `RELEASE_KEY_ALIAS` | `livebeat` |
| `RELEASE_KEY_PASSWORD` | не создавать: у PKCS12 он равен паролю файла |

Дальше: Actions, Build Android APK, Run workflow. В логе шага «Подписать standalone APK
релизным ключом» должны быть строки «APK подписан релизным ключом» и отпечаток SHA-256, он
совпадает с шагом 4. Проверить файл руками:
`C:\Android-SDK\build-tools\36.0.0\apksigner.bat verify --print-certs app-release.apk`,
в `Signer #1 certificate DN` не должно быть `Android Debug`.

## Первая загрузка

Файл: артефакт `livebeat-standalone-apk` (zip, внутри `app-release.apk`) только после сборки с
релизным ключом. Debug-подписанный не грузить: шаг CI в этом случае пишет «Релизный ключ не
задан». Package подставится сам, `com.pulsetracker.app` менять нельзя. Дальше карточка и
анкета из разделов ниже. Обновления: поднять `version` в `app.json`, собрать, загрузить новый
APK (`versionCode` растёт сам).

## Разрешения: что объявлено и что написать в «Назначении»

Список из собранного APK (`aapt2 dump permissions app-release.apk`). Класс по Android, в
консоли сверить.

| Разрешение | Класс | Назначение (текст для поля) |
|---|---|---|
| `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` | опасное | Запись маршрута, дистанции и темпа тренировок на улице и на велосипеде. На Android 11 и ниже система требует его и для поиска Bluetooth-пульсометра. |
| `ACCESS_BACKGROUND_LOCATION` | опасное | Запись маршрута продолжается при погашенном экране, пока идёт тренировка, которую пользователь запустил сам, с постоянным уведомлением. **Рекомендуется убрать, см. вопрос 2.** |
| `BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN` (с флагом `neverForLocation`) | опасное (Android 12+) | Поиск нагрудного пульсометра и подключение к нему по Bluetooth LE для приёма пульса. Местоположение из сканирования не извлекается. |
| `BLUETOOTH`, `BLUETOOTH_ADMIN` | обычное (Android 11 и ниже) | То же. |
| `POST_NOTIFICATIONS` | опасное (Android 13+) | Уведомление на время тренировки с текущим пульсом и временем, сообщение о потере связи с датчиком. |
| `FOREGROUND_SERVICE`, `..._LOCATION`, `..._CONNECTED_DEVICE` | обычное | Служба переднего плана на время тренировки: приём пульса и запись маршрута при погашенном экране. |
| `VIBRATE`, `WAKE_LOCK` | обычное | Вибрация при выходе из целевой зоны; экран не засыпает во время тренировки. |
| `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` | обычное | Загрузка карты (OpenFreeMap). |

Анкета типов данных: местоположение, здоровье и фитнес (пульс), личные данные (возраст, вес,
пол). Везде ответ «обрабатывается только на устройстве, не собирается и не передаётся».

- **Полное** (1799 из 4000):

```
LiveBeat показывает пульс во время тренировки и записывает её: зоны, маршрут, калории, историю. Работает с нагрудным пульсометром по Bluetooth, без аккаунта, без рекламы и бесплатно.

ЧТО НУЖНО
Пульсометр с Bluetooth LE и стандартным профилем Heart Rate (нагрудный ремень, пульсовой браслет). Проверено на Magene H64. Без подключённого датчика тренировку не начать.

ЧТО УМЕЕТ
• Живой пульс и пять пульсовых зон. Максимальный пульс считается по возрасту и полу, а если вы знаете свой, его можно ввести вручную.
• Вибрация и голосовая подсказка, когда пульс выходит из целевой зоны.
• Семь видов тренировок: улица (бег и ходьба), дорожка, велосипед, зал, кроссфит, йога и прочее.
• Улица и велосипед: маршрут на карте, дистанция, темп или скорость, отрезки по километрам без пауз. Маршрут из GPX-файла можно загрузить, он рисуется пунктиром на карте тренировки.
• Голосовые подсказки на бегу: километры, интервалы, выход из зоны.
• Таймеры: отдых между подходами в зале и интервальный таймер для кроссфита (Tabata, EMOM, AMRAP или свои, с шаблонами).
• Пульс восстановления после тренировки.
• Калории по пульсу, возрасту, весу и полу.
• История тренировок, цели на неделю, статистика, личные рекорды и динамика пульса на сравнимом темпе.
• Виджет «Эта неделя» на рабочий стол.
• Экспорт маршрута в GPX, картинка с итогами тренировки для мессенджера, выгрузка и загрузка всей истории одним файлом.
• Уведомление с живым пульсом на время тренировки, запись идёт и при погашенном экране.

ПРИВАТНОСТЬ
Все данные хранятся только на вашем телефоне: нет аккаунта, рекламы и аналитики. Из интернета приложение загружает только карту (OpenFreeMap). Политика конфиденциальности по ссылке в карточке.

LiveBeat не медицинское изделие: пульсовые зоны и калории ориентировочные и не заменяют консультацию врача.
```

Фраза «Без подключённого датчика тренировку не начать» верна, пока не сделан режим без
пульсометра (вопрос 1): после него убрать.

## Политика конфиденциальности

Черновик в `../docs/privacy-policy.md`. Подставить `[почта для связи]` и `[дата публикации]`
(почту выбирает владелец, в текст она сознательно не вписана). Нужна публичная ссылка: самое
простое GitHub Pages из папки `docs` (Settings, Pages, Source: ветка `master`, папка `/docs`),
ссылка вида `https://<пользователь>.github.io/<репозиторий>/privacy-policy`. Репозиторий
собираются пересоздать, ссылка тогда сменится: в консоли её можно поправить, в приложении она
не зашита.

## Открытые вопросы (решает владелец)

1. **Без датчика приложение бесполезно.** Кнопка «Начать тренировку» заблокирована, пока не
   подключён пульсометр (`HomeScreen.tsx`, `disabled={!isConnected}`). У модератора Magene H64
   нет, а правила просят, чтобы заявленные функции работали; у большинства пользователей
   магазина ремня тоже нет. Варианты: а) режим без пульсометра (дистанция, время, темп; идея 12
   в `roadmap.md`), б) подробный комментарий и видео для модерации, в) демо-режим.
   Рекомендация: а), он же расширяет аудиторию. Сканер ищет любой датчик со стандартным
   сервисом Heart Rate (0x180D), но проверено только на H64.
2. **`ACCESS_BACKGROUND_LOCATION` не нужен.** `expo-location` 57.0.19, `LocationModule.kt`,
   `startLocationUpdatesAsync`: запуск «as a user-initiated foreground service with
   notification» не требует фонового разрешения, а мы стартуем именно так (опция
   `foregroundService`, `src/location/backgroundLocation.ts`). Требует его только наш код
   (`requestLocationPermissions`, `checkLocationPermission`) и плагин. Убрать: разрешение из
   `app.json` и флаг `isAndroidBackgroundLocationEnabled`, обе проверки оставить на обычном
   разрешении, поправить подписи в настройках. Выигрыш: нет шага «Разрешить всегда» (на Android
   11+ он уводит в настройки), меньше вопросов модерации. **Проверить на телефоне:**
   прогулка 10 минут с погашенным экраном, маршрут без дыр.
3. **Лишние разрешения из библиотек.** В собранном APK есть то, чем приложение не
   пользуется: `SYSTEM_ALERT_WINDOW` (шаблон Expo), `SCHEDULE_EXACT_ALARM` и
   `ACCESS_NOTIFICATION_POLICY` (Notifee), `READ_EXTERNAL_STORAGE` и `WRITE_EXTERNAL_STORAGE`
   (шаблон Expo, до Android 12). Первые два RuStore отнесёт к особым и будет проверять
   тщательно. Убрать можно одной правкой `app.json`:
   `"android": { "blockedPermissions": ["android.permission.SYSTEM_ALERT_WINDOW", "android.permission.SCHEDULE_EXACT_ALARM", "android.permission.ACCESS_NOTIFICATION_POLICY", "android.permission.READ_EXTERNAL_STORAGE", "android.permission.WRITE_EXTERNAL_STORAGE"] }`.
   Список снят с `app-release.apk` не самой свежей сборки, перепроверить `aapt2` на текущей.
   Вопросы 2 и 3 это одна сборка и одна проверка на телефоне.
4. **Оператор персональных данных (152-ФЗ).** У нас всё на телефоне и разработчику не
   уходит, это сильный довод, что оператором вы не становитесь, но формулировки политики и
   анкеты должны быть аккуратными. Юридической гарантии здесь нет, при сомнении юрист.
5. **Правила Google для установки APK.** Проверка разработчиков начинается 30.09.2026 в
   Бразилии, Индонезии, Сингапуре и Таиланде, дальше 2027. Для России сроки неясны: в одних
   источниках она есть, RuStore в блоге (19.08.2026) её не называет. Для хоббистов есть
   бесплатный режим Limited Distribution до 20 устройств, для публичной раздачи он не
   годится. Сейчас не блокер, следить в 2027
   ([блог RuStore](https://www.rustore.ru/developer/en/blog/google-is-changing-android-app-installation-rules-what-it-means-for-rustore-developers)).
6. **Только arm64-v8a.** Не поставится на редкие 32-битные телефоны. Для магазина решить
   отдельно: ещё одна архитектура это больший APK и дольше сборка.
7. **Название и package.** Уникальность `LiveBeat` и `com.pulsetracker.app` видна только при
   загрузке. Package после публикации не меняется.

## Переезд в новый репозиторий

Ключ лежит вне репозитория и переезжает вместе с владельцем. В новом репозитории заново:
четыре секрета, GitHub Pages для политики и новая ссылка в карточке. Файл воркфлоу и скрипт
подписи переезжают как есть, `versionCode` считается по времени и не уменьшится. Package и
ключ те же, иначе поверх установленного не поставить.
